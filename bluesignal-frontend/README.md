                                        🌊 BlueSignal – AI Powered Marine Risk Intelligence System

🛠️ Tech Stack

Backend:
- Python
- FastAPI
- Machine Learning (Regression, Isolation Forest)

Frontend:
- React

Data & Processing:
- Marine environmental indicators (pH, temperature, salinity, dissolved oxygen)

🤖 Machine Learning Models

- Regression model for marine stress forecasting
- Isolation Forest for anomaly detection
- Composite risk scoring logic combining:
  - current stress
  - predicted stress
  - anomaly signal

🧩 Use Cases

- Fisheries risk monitoring and harvest planning
- Aquaculture farm stress and disease risk detection
- Insurance risk profiling for marine assets
- Coastal regulatory monitoring and reporting
- Supply chain and export risk assessment

🏁 Hackathon Submission

This project was developed as a hackathon proof-of-concept to demonstrate how
marine environmental data can be transformed into predictive economic and
operational intelligence using AI.
